# @proguidegh/contracts

TypeScript API contracts shared by the ProGuideGH web apps
(`tourist-web`, `guide-web`, `admin-web`).

## Phase 0 status

`src/index.ts` contains **hand-written placeholder types** for the API
health/readiness endpoints (`HealthResponse`, `ReadinessResponse`,
`ErrorResponse`). They exist only so frontends compile before the Go API
ships its OpenAPI baseline.

## Regenerating from OpenAPI

Once `docs/api/openapi.yaml` exists (generated by `services/api`):

```sh
pnpm --filter @proguidegh/contracts generate
# or
./scripts/generate.sh
```

This runs [openapi-typescript](https://github.com/openapi-ts/openapi-typescript)
and writes `src/generated.ts` with `paths` and `components` types. At that
point the placeholders in `src/index.ts` should be replaced by re-exports
from the generated file.
